# Changelog

All notable changes to TMT Atlas are documented here.

## [0.1.0] — 2026-10-08

### Added

- Local-first TMT research workbench with no-LLM core path.
- Research overview with search, prompt shortcuts, event feed and company map.
- Company snapshots with metric status and source provenance.
- Sector scans for AI infrastructure/semiconductors, cloud/SaaS, and platform/e-commerce/advertising.
- Event radar separating direct facts, transmission paths, inferences and open questions.
- Markdown and HTML memo generation.
- Official-source registry for company IR, SEC EDGAR, HKEXnews and SSE entry points.
- Optional OpenAI-compatible LLM draft adapter with explicit opt-in and selected-evidence scope.
- Review-first collection-plan endpoint for future authorized news/filing automation.
- Core unittest coverage and GitHub-ready documentation.

### Limitations

- Demo values are illustrative and not live market data.
- Local file ingestion, OCR, SQLite/FTS5, production connectors and external user testing remain next steps.
