# TMT Atlas｜当前能力边界与实现状态

更新时间：2026-10-09

这份文件用于防止 GitHub README、产品演示和面试讲稿把“已实现”“可配置”“已验证”和“设计中”混在一起。

## 已实现并通过自动测试

- 本地 Web 工作台：研究总览、公司快照、赛道扫描、事件雷达、研究备忘录和来源设置。
- 9 家中美 TMT 演示公司、3 个赛道和明确的演示数据警告。
- 本地 PDF/CSV/JSON/Markdown/TXT 证据导入；文件 SHA-256 去重；PDF 页码、文本行、CSV 行定位；可选本地 OCR。
- SQLite 工作区：来源、证据、事实、审核状态和审计记录；事实默认 pending，人工审核后才可 accepted/rejected。
- 证据搜索，包含 FTS5（可用时）和 LIKE 回退。
- 严格金融计算：同比、利润率、CAGR、单位转换、EV/Revenue、P/E、企业价值、自由现金流和简化 DCF；结果带公式、输入、警告和状态。
- 官方来源入口与单独的 `verified_facts.json` 核验语料；核验语料不会自动混入演示数据。
- 授权 RSS/Atom/JSON Feed 收集器：默认关闭、显式授权、最小间隔、最多 5 个 feed、去重、条件请求、审核箱；只保存资讯元数据，不自动批准金融事实。
- OpenAI-compatible LLM 草稿入口；默认关闭；用户可在界面勾选证据后再请求；API key 只从环境变量读取。
- 82 个后端/金融/连接器/证据/集成自动测试已通过（以最后一次本地运行记录为准）。

## 可配置但需要用户主动提供条件

- 外部 LLM：需要用户提供兼容 API 的 Base URL、模型名和 `TMT_LLM_API_KEY`，并明确开启外部发送。
- 资讯收集：需要用户确认来源有权访问和使用，并提供 RSS/Atom/JSON Feed URL；应用运行期间才会执行调度。
- 真实材料研究：需要用户选择有权使用的 PDF/CSV/Markdown/JSON/TXT 文件，并在事实审核台确认抽取结果。
- 真实市场报价：连接器只提供可选适配器和延迟/快照语义，不承诺实时行情或完整市场覆盖。

## 已有官方核验数据

`data/verified_facts.json` 当前包含 Baidu FY2024、Alibaba FY2025 和 Meta FY2024 的一组官方业绩公告事实。它们保留期间、单位、币种、会计口径、合并范围、来源 URL、发布日期和定位说明。

这些数据用于展示“已核验语料如何与演示工作区分离”，不代表已覆盖全部 9 家公司，也不自动证明所有计算或横向比较均可成立。跨公司比较仍需满足期间、币种、单位、会计基础、范围和指标定义的条件。

## 尚未宣称的能力

- 不宣称实时全市场资讯、实时行情、生产级高并发或应用商店上架。
- 不宣称自动投资建议、自动交易或投资收益。
- 不宣称外部用户留存、研究效率提升、模型准确率或引用覆盖率已经达标。
- 不宣称已经完成多 Agent 自主研究；当前 LLM 路径是受控证据草稿，资讯收集是授权且审核优先。
- 不宣称所有公开来源的内容都可以被复制、再分发或打包进仓库。
