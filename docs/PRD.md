## 已冻结的实现范围

第一版产品名称为 TMT Atlas，定位为“一个专注于 TMT 研究的本地优先工作台”。它同时面向金融研究/投研实习生和 AI 产品求职展示，但所有能力围绕同一个研究闭环组织。

核心页面为研究总览、公司快照、赛道扫描、事件雷达、研究备忘录和来源与设置。首批案例覆盖 NVIDIA、SMIC、Microsoft、Alibaba、Baidu、Amazon、Alphabet、Meta、Tencent；首批方向为 AI 基础设施/半导体、云/SaaS、平台/电商/广告。

## P0 可用路径

- 无 LLM、无 Docker、无外部数据库服务即可运行。
- 搜索公司、事件和来源。
- 查看公司快照和来源入口。
- 查看赛道公司×指标矩阵。
- 将事件拆成事实、传导路径、推断和待验证问题。
- 生成 Markdown 和 HTML 研究备忘录。
- 添加本地来源元数据。
- 查看 LLM 和定期收集设置边界。

## P1 可选增强

- OpenAI-compatible 任务草稿接口。
- 只发送用户选定证据片段。
- 显式开启和 API key 环境变量保护。
- review-first 定期资讯收集计划。
- 后续本地文件导入、OCR、SQLite/FTS5 和结构化事实审核台。

## 已知非目标

不提供自动下单、投资建议、收益承诺、默认全网抓取、绕过付费墙、未经许可的报告镜像和实时全市场数据承诺。
